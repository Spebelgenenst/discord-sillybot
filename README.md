# discord silly bot
a discord bot with some silly features tinyllama for ai features!

## features:
- ` /send_message `
send a message through a webhook, that looks like the selected user

- ` /random_gif `
get a random gif from the selected collection

- ` /predict `
predict what will be the next message by a user

- ping the bot to get an ai generated answer

## install

create a virtual enviorment
```
python -m venv .venv
```

enter
```
source .venv
```

install packages
```
pip install discord.py torch transformers accelerate
```
